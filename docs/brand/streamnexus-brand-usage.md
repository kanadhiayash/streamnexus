# StreamNexus Brand Usage

Owner issue: #34

StreamNexus uses the `SNX` product code with the Connected Play Nexus mark and the tagline `DISCOVER • CONNECT • ACCESS`.

Use the dark horizontal lockup on light surfaces and the light horizontal lockup on dark surfaces. Use the standalone mark for compact navigation, favicons, and app icons. Do not replace the production assets with text-only `SN` placeholders.

Production assets live in `public/brand/`. The validation contract is tracked by `SNX-BRAND-001` through `SNX-BRAND-006`, with accessibility and SVG-safety checks tracked by `SNX-A11Y-001` and `SNX-SEC-002`.
