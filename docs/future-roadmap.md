# Future Roadmap

This roadmap tracks useful follow-up work that is not fully implemented in the current release.

## Product

- Add personalized recommendations based on rentals, shortlist activity, genres, and ratings.
- Add a watch-history UI that uses the existing model shape for progress tracking.
- Add richer admin analytics for top rentals, revenue estimates, and content availability.
- Add media asset management for content posters and thumbnails.
- Add more advanced filtering by genre, rating, price, and availability.

## Engineering

- Add browser-based end-to-end tests for critical admin and streamer workflows.
- Add pagination for larger content and rental lists.
- Add production deployment documentation for a selected hosting provider.
- Add structured logging for production observability.
- Add database indexes aligned with high-traffic browse and search paths.

## Security

- Add password reset flows.
- Add stronger password policy for non-demo users.
- Add audit logging for admin content changes.
- Add stricter production Content Security Policy settings after asset hosting is finalized.
